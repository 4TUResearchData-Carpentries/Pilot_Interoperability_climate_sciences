# Interoperability in Climate and Atmospheric Sciences: FAIR NetCDF Data workshop

Welcome to the pilot workshop on FAIR, interoperable NetCDF data for climate and atmospheric sciences. This repository contains the lesson materials and setup guidance for the 22 October 2026 event.

[![schema.org Course](https://img.shields.io/badge/schema--org-Course-blue.svg)](./schema-course.jsonld)

## 🚀 Workshop Overview

This hands-on workshop introduces practical approaches to making climate and atmospheric science datasets easier to find, access, integrate, and reuse through shared standards, rich metadata, persistent identifiers, and semantic descriptions.

## 🛠 Prerequisites

Before attending, please ensure you have:

- Basic Python experience (write and run short scripts)
- Awareness of the NetCDF format
- A laptop for hands-on exercises
- A Unix-like terminal (Git Bash, WSL, or Mac/Linux Terminal)
- Python 3.11+ and `uv` installed
- Optional: `jq` for API-related exercises

See [Lesson_development/setup.md](Lesson_development/setup.md) for installation instructions.
